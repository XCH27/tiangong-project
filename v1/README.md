# OmniVerse Vision V1 Terminal UI

This repository contains the standalone Textual Terminal UI (TUI) and legacy Typer CLI for the OmniVerse Vision project.

## Relationship to Core Project
This is an independent frontend shell. It relies on a standard OmniVerse REST backend to perform semantic video parsing and retrieval.

## Installation
Use `uv` to sync dependencies and install the local backend:
```bash
uv sync
```

## Usage
Run the TUI using the `oe` command:
```bash
uv run oe
```
