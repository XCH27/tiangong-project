# Design library — retained intent and source evidence

This library explains current owner intent and retains unique source comparisons. It supplies no
competing architecture or execution order. [PRODUCT](../PRODUCT.md) owns precedence; specs and
suite packets own implementation and acceptance. Absorbed legacy M02–M19 plans have been removed.

| Area | Canonical requirements / retained evidence |
|---|---|
| Owner intent | [Owner Voice](OWNER-VOICE.md), [Product](../PRODUCT.md) |
| Project and remote interaction | [Project/Workspace note](20-workspace-project-session-remote-connections.md), [R1](../specs/R1-one-boundary-language.md) |
| Visual values and motion | [UI specification](../UI-SPEC.md), [Motion](22-motion.md); compare current Craft source before UI edits |
| Canvas | [SYS-05](../modules/suites/SYS-05-design-spatial.md), [source evidence and workload gate](07-canvas-spatial-orchestration-VISION.md) |
| Package interoperability | [source comparisons](12-capability---skill---plugin-system.md), [SYS-08](../modules/suites/SYS-08-marketplaces.md), [SYS-09](../modules/suites/SYS-09-workspace-compositions.md) |
| Execution, files, browser, memory, media and workflows | [Suite index](../modules/suites/README.md), [Architecture](../04-ARCHITECTURE.md), [active baseline](../specs/R0-baseline-audit.md) |

Keep a note only while it has unique active intent or reproducible evidence. Absorb it, update
links and delete it when superseded; Git history is the recovery path, not an in-tree archive.
This rule does not authorize pruning external source checkouts, user files or license notices.
Reference checkouts and UI collections remain under the owner-controlled roots recorded in the
[reference registry](../references/REFERENCE-REGISTRY.md).
