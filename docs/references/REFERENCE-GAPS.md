# Reference audit gaps

The product matrix names candidates, but a name is not evidence. This file makes remaining
reference work visible instead of allowing the matrix to imply approval.

The current fact check is in [`REFERENCE-REGISTRY.md`](REFERENCE-REGISTRY.md). It confirms that
Most non-Craft rows in `REVIEWED-HEADS.tsv` are still `pending` under admission-v2; `plugins/xyflow`
is source-reviewed but remains `INSUFFICIENT_COMPARISON`. Exact local
paths and root license text do not substitute for a mechanism-level admission.
The concrete file/symbol audit for the highest-risk routes is in
[`ADMISSION-V2-AUDIT.md`](ADMISSION-V2-AUDIT.md).

import a candidate checkout merely because it appears in a design document.
