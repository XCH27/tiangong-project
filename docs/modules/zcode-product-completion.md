## State and proof boundary

### W — selected native whiteboard loop

Retain the current fixed 1280×800 stroke document/pane; it is not SpatialDocument. Canonical
bytes live at `{original Session workspace}/.zcode/whiteboards/{lowercase UUID}.json`. Version-1
JSON contains current board fields, logical revision and last mutation identity. Unknown
versions/corruption are visible and never overwritten. Inputs are bounded: 8 MiB serialized,
4,096 strokes, 200,000 total finite in-bounds points, 128-character name, fixed dimensions.
Limits reject with draft/export retained, not silent truncation. No new DB/content authority.

One registered ReadWhiteboard/WhiteboardUpdate pair owns native parsing/mutation through the
original FileSystemPort. Agent and explicit human Save share that operation/ToolExecutor,
permission broker, Session events and native checkpoint output. Updates require current file
revision/hash or explicit expected absence; stale/symlink-escaped writes have zero effect.
FileSystemPort adds optional `expectedAbsent` and `boundaryRoot` (read/write/directory listing) for this concrete
consumer only. The original adapter checks within its write lock and before atomic publication,
canonicalizing the bounded workspace root; original calls preserve behavior.

Human entry is a narrow authenticated Session control command limited to the native tool. No
arbitrary tool/shell name, model-visible approval flag or workspace outside the Session. Reuse
original foreground lease/residency/abort and event/store owners; no second accepted queue.
Refuse busy safely with retry and retained draft. Mutation identity is stable on retry; a
committed same-identity mutation is observed without a second effect. Save initially exercises
original explicit approval, including destructive clear/replace; denial writes no workspace file.
No inference/title-generation call is needed to persist human ink. Do not invent an AI result.
Agent plan mode filters Agent-visible mutation tools. An explicit human native Save may still
use its narrowly admitted operation after the same high-risk explicit approval, including in
plan/yolo. It does not change mode, grant permissions, or expose a generic action to the model.

The Host entry is `session/whiteboardControl` through the existing authenticated Agent service.
It waits for the actual registered tool receipt and checkpoint, not an optimistic acknowledgement.
The original NDJSON transport admits only existing V4 Stop/interaction responses around that long
control; they retain original command admission and exact foreground identity. Cold activation
derives stored Session workspace before comparing caller scope, never rebinding from input.
Native preimages are prepared before file publication in the existing ArtifactStore and Session
journal. The same checkpoint writer publishes them; failed publication is repaired by observing
existing file/receipt facts on cold reopen or the next native control, without rerunning a tool.

UI retains RAM boards as drafts until durable ACK, adds Save/Open/refresh/export in the current
pane, shows unsaved/error/conflict and fences workspace/Host/board generations. Reload merges
with live drafts, never resets before ACK. Dirty pane/app close offers Save/Discard/Cancel through
original confirmation/close ownership. Losing a draft requires explicit discard. Agent/native file
edits refresh the same document; conflict keeps committed state and unsaved drawing inspectable.
Existing PNG-to-chat remains. ArtifactStore holds derived receipts/exports, not editable authority.

Acceptance: registered tools + original broker + file CAS + actual SQLite, human/Agent parity,
deny/Stop/save failure/late ACK/Host change, two-process create race, cold reopen, rendered pane,
checkpoint/revision and zero paid/model transport. No generic writer on read-only FileService.

Original admission/Runtime/App/Session and canonical plugin/registry/workflow/store owners remain.
UI request generations are projections only. Source extraction preserves closures, receiver,
evaluation order, public ABI and identity; class/runtime owners are not cloned. Existing tests and
staged binaries must exercise unchanged production behavior after extraction, including mobile
