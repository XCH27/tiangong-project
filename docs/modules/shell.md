## Settled visible boundary; storage migration still pending

The owner-selected visible path is **Host → optional Project/folder → Conversation**. Host identifies
this device or one user-owned remote runtime. A Project is a folder on that Host; a Conversation
may be Project-bound or folderless. Installed capabilities belong to a catalog; each Project
selects its suites, Skills, Sources/MCP and right tools. The accepted turn snapshot cannot grant
file, network or OS permissions.

The visible boundary is settled; compatibility storage is not yet migrated. Craft currently
uses Workspace paths in Session, Project, Source, Skill and remote routing. Retain a compatibility
read path until an inventory proves where every old record appears, how two old Workspaces naming
the same folder remain distinct, how local/remote path identity works on Windows/macOS/Linux, and
how a disconnected host or unavailable suite is shown without data loss. Do not auto-merge or
delete records. The UI may eventually hide Workspace only after those proofs exist.
