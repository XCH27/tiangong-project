## Assignment rule

An Agent receives one packet, one active spec, and one bounded code seam. It must report the fixed
status vocabulary, attach the named evidence commands, and stop at the shared-contract or owner
checkpoint described in the packet. “Designed” or “researched” never promotes a capability to
`usable`.
