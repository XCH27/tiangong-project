# Legacy Documentation Index

To optimize context window efficiency and prevent token bloat during searches and workspace reads, all historical Chinese project documents have been compressed into a single zip archive.

These files represent historical evidence and design evolution, not the active roadmap. Active project development follows the English active documentation under `docs/`.

## Archive Location
The complete archive is located at: `docs/legacy/legacy-corpus.zip`

### How to Restore / Extract
To inspect a specific historical document, extract the corpus using standard zip tools:
```bash
unzip docs/legacy/legacy-corpus.zip -d docs/legacy/extracted/
```
