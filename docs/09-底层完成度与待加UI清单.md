## 2 · 工作流约定（防跑偏）

1. **底层先行**：我/执行 agent 把上表 ⬜ 的底层写成**带测的服务/逻辑件**（接口隔离，见 `07`），写完把状态改 ✅ 并标"待加按钮：X → 连 Y"。
2. **按钮后接**：之后用**能看屏幕 + 网页注释的 UI agent**，照本清单在真实界面上加入口、连到对应 service/RPC——它能看到真实渲染，比凭空画准。
3. **铁律不变**：新增本机 RPC 标 `LOCAL_ONLY`；危险动作走 craft permission + 证据 + EventStream；**不另起第二套 session/config 真相**；显示层（汉化）只读旁路、不改执行原文。
4. **这份清单是"接线表"**：UI agent 加的每个按钮，都能在表里查到"点了该调用谁"。
