## 记录要求

每次迁移 craft/AionUi 源码时都要新增一行。字段含义：

- 日期：迁移进入 Fleet 的日期。
- Fleet 模块：服务哪个功能，例如 CLI Runtime、Agent Team、Skill Registry。
- 来源项目：只能是当前绿灯表中的项目。
- 来源路径：原项目文件/目录路径。
- 来源版本：commit、tag 或清晰日期。
- 迁移方式：完整复制、局部复制、改写、模式迁移。
- 许可证/归因处理：是否保留文件头、SPDX、NOTICE、第三方声明。
- 修改说明：为了适配 Fleet/craft 做了什么改动。

未写入本清单的迁移视为不合规，需要补齐后再继续开发。
